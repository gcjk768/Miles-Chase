# Conventions

Flat vault, atomic notes, `[[wikilinks]]` over tags; tags only for status (`#active`, `#archived`). Update [[Changelog]] and [[App Overview]] on every code change; App Overview links are path-qualified (`../../file.py`). Move stale notes to an `Archive` note, don't delete.
